1. **Кадр в норме:** 9,88 мс базово — это ~101 FPS, запаса до 16,6 мс (60 FPS) более чем достаточно. Тяжёлые подсистемы (фантомы, тепловая карта) работают **в фоне и дешевле базового кадра** — потому что размазаны по кадрам.
2. **Планирование — самая дорогая операция:** генерация 8 траекторий 0,22–3,07 с, одно решение IK 5,7 мс. Это ожидаемо для CCD-решателя с 160 итерациями и 3 стартовыми приближениями (см. `CODE_AUDIT.md` §4) и является осознанным компромиссом «качество ветвей против времени». Для интерактивной работы приемлемо, для реального времени — нет.
3. **Интерфейс — второе по стоимости:** 53–62 мс на полную пересборку. **Но** в кадре этого не происходит: панели обновляются по таймерам 0,1 / 0,2 / 0,4 с (0,769 мс/тик), дерево — только при изменении подписи. Это правильная архитектура, зафиксированная ещё в §0.4.
4. **Вход в PlayMode стоит 8,5 с** — это цена редактора Unity (перезагрузка домена на проекте с 25 пакетами и HDRP), а не кода проекта.
5. **Старт сцены** (сумма всех `Awake`/`Start`) отдельно не измерялся. По статике это ~60 объектов сервисов + ~2 933 записи локализации + построение 269 объектов канваса; ориентир — те же 53,4 мс на построение оболочки.
